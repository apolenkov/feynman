# Support

- **Bug or unexpected output:** open a
  [bug report](https://github.com/apolenkov/feynman/issues/new?template=bug_report.md).
  Include `feynman version`, Node.js and Codex versions, and the smallest input
  that reproduces it.
- **Idea or missing capability:** open a
  [feature request](https://github.com/apolenkov/feynman/issues/new?template=feature_request.md).
- **Security issue:** report it privately, see [SECURITY.md](SECURITY.md).
- **Usage questions:** start with the [README](README.md),
  [docs/](docs/) and `feynman doctor`, then open an issue if they do not answer it.

This is a solo-maintained project; replies are best effort.
